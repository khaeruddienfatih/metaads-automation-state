PARSING CURRENCY: field amount_spent berformat string Indonesia contoh "Rp220.000 IDR" atau "Rp0 IDR", atau object {"value":"220000","unit":"IDR"}. Untuk string: buang "Rp","IDR",spasi, lalu buang semua titik "." (pemisah ribuan bukan desimal) -> integer rupiah. Untuk object: pakai value sebagai integer rupiah.

PARSING "hasil": gunakan field `results` (indicator actions:onsite_conversion.messaging_conversation_started_7d). Kalau results.value=="Not available" atau field tidak ada -> hasil=0. Kalau ada results.values[] -> jumlahkan value numeriknya.
